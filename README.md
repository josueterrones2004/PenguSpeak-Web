PenguSpeak Web is the official website for **PenguSpeak**.

This repository contains only the public-facing website: project information, feature highlights, voice demos, legal pages and links to the main bot repository. The Discord bot itself is developed separately in the [PenguSpeak repository](https://github.com/josueterrones2004/PenguSpeak).

## 🌐 About the site

The website is designed to provide a simple place to:

- Learn what PenguSpeak does.
- Explore its main features.
- Listen to available voice demos.
- Access the bot repository and releases.
- Read the Terms of Service and Privacy Policy.

## 🇪🇸 Spanish-first project

PenguSpeak is specifically designed for **Spanish-speaking Discord communities**.

The bot currently provides Spanish voices and Spanish-oriented spoken behavior. There are no current plans to add English voices.

The website may contain English-facing project documentation for clarity and discoverability, but the bot itself remains focused on Spanish TTS.
